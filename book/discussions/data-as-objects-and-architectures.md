# Discussion questions

1.	BIDS assumes a small number of participants and standardized measures. Large behavioral studies often violate both assumptions. How would you redesign the data architecture for a large-scale psychological study with many measures? What metadata would you include to track participants across files, and what complications might arise?

2.	What assumptions about the world are baked into a data tables and how would those assumptions fail in a different context? When does forcing data into tables erase important structure?
